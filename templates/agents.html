⬡ Multi-Agent Architecture

Agent Pipeline

RiskSense AI coordinates three specialized agents around your preserved fraud detection model — each with a distinct responsibility and structured data contract.

⬡ System Architecture

The Agentic Pipeline

Each loan application moves through a deterministic sequence of agents — no hallucination, no guesswork.

⬡

RiskSenseOrchestrator

Workflow Control

Receives loan applications from the Flask routes, sequences agent execution in strict order, and assembles the unified AgenticReport dataclass with audit trail and executive summary.

🛡️

Detection Agent

ML Fraud Scoring

Invokes loan_fraud_ensemble_model.pkl and preprocessor.pkl without modification. Returns fraud probability, binary label at 40% threshold, and confidence band to the orchestrator.

📊

Analytics Agent

Feature Risk Interpretation

Evaluates CIBIL score, DTI ratio, loan-to-income, existing EMI burden, employment stability, and age bracket against banking heuristics. Produces a composite risk score (0–100) with explainable severity-coded signals.

⚖️

Advisory Agent

Fraud Operations & Lending Guidance

Synthesizes ML output and analytics into prioritized banking actions (P0–P3): block & escalate, EDD trigger, manual review routing, STR filing, or standard approval path with compliance disclaimers.

⬡ Agent Specifications

Responsibilities & Data Contracts

Each agent operates with strict input/output contracts via Python dataclasses.

⬡

RiskSenseOrchestrator

Pipeline Coordinator

The central orchestration layer. Accepts raw form data from Flask routes, sequences each agent call, and assembles the final report. Handles both manual input and dataset sampling modes.

Outputs
AgenticReport dataclass
workflow_steps trace list
executive_summary string
Chat response via chat_response()
🛡️

Detection Agent

ML Fraud Scoring

Wraps your saved pickle artifacts. Preprocesses raw form data through preprocessor.pkl, scores via loan_fraud_ensemble_model.pkl, and applies the 40% fraud threshold — zero changes to trained weights.

Outputs
probability (float 0.0–1.0)
label ("FRAUD" | "GENUINE")
is_fraud (bool)
confidence_band (str)
📊

Analytics Agent

Feature Risk Interpretation

Rule-based risk signal engine that interprets 14 loan features against banking domain heuristics. Produces both a composite score and human-readable signal explanations for each risk factor.

Risk Factors Evaluated
CIBIL credit score (300–900)
Debt-to-income ratio
Loan-to-income multiple
Employment & age signals
⚖️

Advisory Agent

Fraud Operations Guidance

Synthesizes ML probability and analytics risk score into prioritized banking actions. Enforces compliance disclaimers and generates STR, EDD, or manual review triggers based on combined signal strength.

Action Priorities
P0 — Block & escalate immediately
P1 — EDD / STR filing trigger
P2 — Manual review queue
P3 — Standard approval path
