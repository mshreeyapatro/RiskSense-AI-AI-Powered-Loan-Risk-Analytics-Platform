POST /api/analyze

Runs the full 3-agent pipeline (Detection → Analytics → Advisory) on a single loan application. Returns fraud probability, composite risk score, risk signals, and advisory actions.

Request Body
FieldTypeRequiredDescription
loan_typestringYese.g. "Home Loan", "Personal Loan"
loan_amountnumberYesRequested loan amount in currency units
tenureintegerYesLoan tenure in months
interestdecimalYesInterest rate in % (e.g. 12.5)
purposestringYesPurpose of loan
employmentstringNoEmployment status
incomenumberNoMonthly income
cibilintegerNoCIBIL credit score (300–900)
Example Request
{ "loan_type": "Business Loan", "loan_amount": 2500000, "tenure": 48, "interest": 14.5, "purpose": "Business Expansion", "employment": "Self-Employed", "income": 85000, "cibil": 620, "emis": 15000, "dti": 0.58, "age": 38, "gender": "Male", "dependents": 2, "property": "Rented" }
Example Response
{ "platform": "RiskSense AI: Agentic Banking Fraud Analytics...", "timestamp": "2026-08-02 14:00 UTC", "prediction": { "label": "FRAUD 🚨", "probability": 0.673, "is_fraud": true }, "analytics": { "risk_score": 82, "risk_level": "Critical", "signals": [ { "factor": "CIBIL Score", "severity": "medium", "detail": "Score 620 is moderate" }, { "factor": "Debt-to-Income", "severity": "high", "detail": "DTI 0.58 exceeds limit" } ] }, "advisory": { "decision": "BLOCK & ESCALATE", "items": [ { "priority": "P0", "action": "Freeze application workflow", "rationale": "..." } ] }, "executive_summary": "BLOCK & ESCALATE — FRAUD 🚨 at 67.30% fraud probability." }

POST /api/batch

Process up to 500 loan applications in a single request. Returns aggregate statistics plus per-row results. Ideal for portfolio screening.

Example Request
{ "applications": [ { "loan_type": "Home Loan", "loan_amount": 5000000, "tenure": 240, "interest": 8.5, "purpose": "Home Renovation" }, { "loan_type": "Personal Loan", "loan_amount": 200000, "tenure": 24, "interest": 16.0, "purpose": "Wedding" } ] }
Response Summary Fields
FieldTypeDescription
totalintegerTotal applications processed
fraud_countintegerNumber flagged as fraud
fraud_ratedecimalFraud percentage (0–100)
total_portfolio_valuenumberSum of all loan amounts
estimated_fraud_exposurenumberEstimated fraud-linked portfolio value
resultsarrayPer-row results

🔑 Authentication

RiskSense AI currently runs in open mode — no API key is required. All endpoints are accessible without authentication headers. For production deployments, implement JWT or API key middleware.
